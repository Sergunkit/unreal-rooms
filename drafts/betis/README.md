## Флоу прохождения (зафиксировано)

Прохождение = **good-end бронирования**. Два пути:
1. Промокод **MOTHER** (выцарапан на кресле-качалке на террасе, клик по картинке).
2. Ключ **betis-room1-key** из капчи Дельфина + бронь **любого номера, кроме №1** (логика: Норман с ножом придёт в твой номер, а ты прячься в «не сдающемся» №1).

Wrong-end: бронь кабины №1 («Историческая») или люкса «Мама».
После good-end: отель помечается пройденным → при возвращении в потеряшках открывается чемодан $40 000.
До прохождения потеряшки закрыты: «Содержимое коллекции оставленных вещей скрыто хозяином.»

## Код-доработки при раскатке (малые, список для реализации)

1. **`caption` у артефактов** — поле в artifact_json; в ArtifactModal/LostAndFoundModal рендерить caption вместо «Вы нашли артефакт!», фолбэк на старый текст.
2. **Скрытые потеряшки** — до прохождения отеля список заменяется сообщением «Содержимое коллекции оставленных вещей скрыто хозяином.» Источник истины прохождения — good-end бронирования (см. п.3).
3. **Пометка прохождения при good-end** — при endBookingMessage (не wrong) ставить отелю solved (progress или account state).
4. **`artifact` у item'а капчи** — клик по «неправильному» ключу с полем artifact выдаёт артефакт, капча не падает. Сверить, где живёт капча Дельфина на проде (локально в catalog.json у отеля 5 поля captcha нет; dolphin.json-шаг — текстовый).
5. **Координаты кликов** в chain-draft.json — примерные, выставить по фактическим картинкам.
6. **wrong-end для люкса «Мама»** — сейчас wrong-сообщение одно (про №1); если движок позволяет ветвление по roomType, сделать второе: «Апартаменты заняты постоянной гостьей. Очень постоянной.»
